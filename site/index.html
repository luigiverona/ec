EC

A terminal mouse click controller for Linux and Wayland.

Install

curl -fsSL https://ec.luigiverona.dev/install | sh

Inspect the script before running it.

After installation, run ec setup.

Usage

ec setup
Configure device access and select a mouse.
ec doctor
Check system readiness.
ec start
Start at the default 20 CPS.
ec 100
Start at a custom rate from 1 to 600 CPS.
ec status
Show the current state.
ec stop
Stop EC.

Requirements

  • Linux
  • x86_64 or aarch64
  • evdev/uinput access
  • Wayland supported, including Hyprland

Synthetic clicking may violate game or service rules.
